# Stack

One-page portfolio site (Vite + React) deployed to GitHub Pages.

| Area             | Technologies                           | Evidence                                  |
| ---------------- | -------------------------------------- | ----------------------------------------- |
| Language/runtime | TypeScript • Node.js 20+               | `.nvmrc`, `tsconfig.json`                 |
| UI               | React 18 • Vite                        | `package.json`                            |
| Styling          | Tailwind CSS • PostCSS • Autoprefixer  | `tailwind.config.ts`, `postcss.config.js` |
| Testing          | Vitest                                 | `package.json`                            |
| Quality          | ESLint • Prettier • TypeScript (`tsc`) | `package.json`                            |
| CI/Security      | GitHub Actions (CI) • CodeQL           | `.github/workflows/*`                     |
| Deployment       | GitHub Pages (Actions deploy)          | `.github/workflows/deploy-pages.yml`      |
